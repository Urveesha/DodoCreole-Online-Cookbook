# DodoCreole - Online Mauritian Cookbook

## Project Overview

DodoCreole is a web-based cookbook developed as part of a university assignment at Curtin University Mauritius. The website showcases Mauritian recipes through an interactive and user-friendly interface, allowing users to explore traditional dishes and cooking tips.

## Technologies Used

- React.js
- JavaScript
- HTML & CSS
- Vite
- WordPress (Headless CMS)
- WordPress REST API

## Key Features

- Interactive homepage with a customised design
- Recipe listings and individual recipe pages
- Search functionality for browsing recipes
- Cooking tips section
- Dynamic content integration with WordPress
- Responsive website interface

## My Contributions

Developed and customised the frontend interface using React, implemented recipe and cooking tips pages, integrated WordPress content and enhanced the website's navigation and user experience.

## Running the Project Locally

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Configure the WordPress backend connection using `.env.example`.
4. Start the development server using `npm run dev`.

**Note:** The project requires access to a configured WordPress backend to display dynamic content.

## Project Context

Developed for ISYS3004 Assessment 2 at Curtin University Mauritius, using a provided starter template that was extended and customised for DodoCreole.
